# Reforma Digital para Mac — launch film (PR samuelcorsan/reforma-digital#156)

## Session 1 — 2026-10-18

**Strategy:** 60 s, 16:9, 30 fps, Spanish. Same structure as the reference "Aside" launch film (dark kinetic
problem act → product reveal → white tagline → real app demo → privacy act → URL end card), built from
scratch as a HyperFrames composition (`film/`) using PR #156's design tokens and the app's own copy. No
footage to cut, so the video-use transcript/EDL pipeline does not apply; its animation, self-eval, audio
and critic rules do.

**Decisions:**

- User chose: Spanish, ~60 s (no comparison table / capabilities roll), SFX only (music bed added later),
  build straight away without storyboard sketches.
- Scenes: hook 0–12.5 · reveal 12.5–17 · tagline 17–21.5 · demo 21.5–43 · privacy 43–54 · close 54–60.
- Demo = the real UI of `apps/desktop` rebuilt at native size inside a camera (sidebar, home composer,
  «Pensando» step line with site chips, «El asistente puede hacerlo por ti», browser panel, «Necesito tu
  permiso» + Aprobar, «Listo»). Zooms crop exactly to the 1020 px main area (scale 1.88).
- The portal in the demo browser is an invented mock (no official branding); test data is invented
  (Lucía Martín Gómez, 12345678Z, 600 123 456).
- No competitor logos. Claims limited to what the PR states.
- SFX: bundled media-use library (click-soft, pop, key-press, typing, whoosh, whoosh-cinematic,
  impact-bass, glitch, chime), 49 cues generated by `edit/scripts/sfx.py` into `index.html`.

**Reasoning log:**

- Privacy beat changed from «La IA solo ve {{…}} marcadores.» to «La IA solo ve esto:» + scramble — the
  first read as a broken sentence and was on screen ~0.1 s.
- Demo muted text darkened to #6b6b6b (app uses #737373) to pass WCAG AA in `hyperframes check`.

**Outstanding:** critic pass on preview.mp4; final render at delivery quality with audio peaks ≈ −1 dBTP;
music bed (user).
